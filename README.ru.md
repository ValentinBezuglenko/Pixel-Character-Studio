# Pixel Character Studio

[English](README.md) · [Русский](README.ru.md) · [Español](README.es.md) · [中文](README.zh-CN.md)

Самостоятельный браузерный редактор для рисования пиксельных персонажей 16×16 и создания покадровой анимации. Работает локально, не требует аккаунта или сервера и не связан с какой-либо игрой.

## Возможности

- редактор 16×16 с сеткой, ластиком, отменой и повтором действий
- создание, дублирование, удаление и изменение порядка спрайтов и кадров
- настройка длительности кадра и предпросмотр анимации в масштабе 1×, 2×, 4×, 8× или 10×
- полупрозрачный показ предыдущего кадра
- встроенная палитра и добавление собственных цветов
- поиск и группировка спрайтов
- автоматическое локальное сохранение и до пяти ручных версий
- импорт и экспорт проекта в JSON
- импорт PNG 16×16 и экспорт текущего кадра в PNG
- экспорт спрайт-листа в ZIP с PNG и JSON-атласом
- интерфейс на английском, испанском, русском и упрощённом китайском
- три редактируемых примера анимации персонажей

## Локальный запуск

Сборка не требуется. Скачайте репозиторий и откройте `index.html` в современном браузере.

Для запуска через локальный сервер выполните в папке проекта одну из команд:

```bash
python -m http.server 8000
```

```bash
npx serve .
```

После этого откройте `http://localhost:8000` или адрес, указанный сервером.

## Публикация через GitHub Pages

1. Отправьте проект в GitHub.
2. Откройте **Settings → Pages** в репозитории.
3. Выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`.

Проекты сохраняются в `localStorage` браузера. Для переноса работы между браузерами или компьютерами экспортируйте проект в JSON.
